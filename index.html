The problem

AI made copying an app cheap.

Ship a desktop app and you ship its binary. Open-source models now turn binaries back into working code, and AI agents can explore an app screen by screen to rebuild it.

  • Obfuscation only buys time
  • Every install ships the code

Measured, not promised

We don't just promise detection. We measure it.

We ran 100 simulated sessions for each kind of attacker through the detector that powers the live demo, and compared it with a plain rate-limit rule. v1 uses calibrated weights. v2 adds a logistic-regression model trained on 10,612 labelled session prefixes, with seed 777 held out from training.
